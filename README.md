# المؤذّن: مواقيت الصلاة

تطبيق آيفون لمواقيت الصلاة مكتوب بـ SwiftUI وWidgetKit، وتصميمه مستوحى من تطبيق المصلي.

## المميزات

- **الشاشة الرئيسية:** فيها عدّاد تنازلي للصلاة القادمة بالساعة والدقيقة والثانية، واسم المدينة، والتاريخ الهجري (أم القرى) مع الميلادي، وتقدر تتنقل بين الأيام. تحتها الصلوات الست، ومنتصف الليل، والثلث الأخير.
- **الودجت:** نسخة عريضة بنفس تصميم ودجت المصلي، ونسخة صغيرة، ونسخ لشاشة القفل (مستطيلة ودائرية وسطرية).
- **تنبيهات الأذان:** تجي لكل صلاة، ولك تفعّل تنبيه قبل الأذان بـ 5 أو 10 أو 15 دقيقة. يرتّب التطبيق تنبيهات الأيام الجاية تلقائيًا كل ما فتحته.
- **الموقع:** يتحدد بالـ GPS ويطلع لك اسم المدينة تلقائيًا، أو تختار من قائمة مدن السعودية والخليج وغيرها.
- **القبلة:** بوصلة حقيقية تشتغل بحساس الاتجاه في الجوال، ويهتز الجوال لما تكون متجه للقبلة.
- **الأذكار:** أذكار الصباح والمساء وبعد الصلاة، مع عدّاد لكل ذكر.
- **أقسام ثانية:** السبحة، والدعاء، وحاسبة الزكاة، وجدول الأسبوع، وعمل اليوم والليلة.
- **طرق الحساب:** فيه 10 طرق، منها أم القرى (والعشاء في رمضان بعد المغرب بـ 120 دقيقة)، ورابطة العالم الإسلامي، ومصر، والكويت، وقطر، والإمارات. ولك تختار حساب العصر على الجمهور أو الحنفي.

## البناء بدون ماك (GitHub Actions → TestFlight)

### مرة واحدة فقط

1. **سجّل معرّفات التطبيق.** ادخل [developer.apple.com → Identifiers](https://developer.apple.com/account/resources/identifiers/list) وسجّل هالمعرّفات الثلاثة:
   - App Group باسم `group.com.zxe088.almuadhin`
   - App ID باسم `com.zxe088.almuadhin`، وفعّل فيه App Groups واختر المجموعة اللي فوق
   - App ID باسم `com.zxe088.almuadhin.widget`، وفعّل فيه App Groups بنفس المجموعة
2. **أنشئ التطبيق في App Store Connect.** من [appstoreconnect.apple.com](https://appstoreconnect.apple.com) اختر My Apps ثم ➕ New App. حط الاسم «المؤذّن: مواقيت الصلاة» واختر Bundle ID `com.zxe088.almuadhin`.
3. **أنشئ مفتاح API.** من App Store Connect روح إلى Users and Access ثم Integrations ثم App Store Connect API، وأنشئ مفتاح بصلاحية **Admin**. نزّل ملف `AuthKey_XXXX.p8`، وانسخ Key ID وIssuer ID.
4. **أضف الأسرار في المستودع.** في GitHub روح إلى Settings ثم Secrets and variables ثم Actions، وأضف هالأسرار:
   | الاسم | القيمة |
   |---|---|
   | `APPLE_TEAM_ID` | Team ID، تلقاه في developer.apple.com/account تحت Membership details |
   | `ASC_KEY_ID` | Key ID حق المفتاح |
   | `ASC_ISSUER_ID` | Issuer ID |
   | `ASC_KEY_P8` | محتوى ملف ‎.p8 كامل، افتحه بأي محرر نصوص وانسخه كله |

### كل ما تبي نسخة جديدة

1. في GitHub روح إلى Actions ثم **TestFlight** ثم **Run workflow**.
2. بعد حوالي 10 إلى 20 دقيقة تطلع النسخة في App Store Connect تحت TestFlight.
3. نزّل تطبيق **TestFlight** على الآيفون. بتوصلك دعوة على إيميل حساب المطور، أو ضيف نفسك كمختبر داخلي.

## ملاحظات

- **صوت الأذان:** إذا تبي صوت أذان بدل صوت التنبيه العادي، حط ملف باسم `adhan.caf` في مجلد `App/`. لازم مدته تكون 30 ثانية أو أقل، وتقدر تحوّل أي ملف صوتي بالأمر `afconvert -f caff -d LEI16 in.mp3 adhan.caf`. التطبيق يستخدمه تلقائيًا إذا لقاه.
- **حد التنبيهات:** iOS يسمح بـ 64 تنبيه مجدول كحد أقصى. يعني التطبيق يغطي 12 يوم، أو 6 أيام إذا فعّلت التنبيه قبل الأذان. افتح التطبيق مرة كل كم يوم عشان يجدّد التنبيهات.
- **فحص البناء:** ملف `Build` في GitHub Actions يبني التطبيق تلقائيًا مع كل تحديث، ويتأكد إن حساب المواقيت صحيح.

## هيكل المشروع

```
project.yml            تعريف المشروع (XcodeGen)
Shared/                حساب المواقيت، الإعدادات، تصميم الودجت (مشترك بين التطبيق والودجت)
App/                   شاشات التطبيق
Widget/                الودجت
Tests/main.swift       فحص دقة المواقيت
.github/workflows/     البناء التلقائي والرفع إلى TestFlight
```
